# 새봄약속 — 약속의 말씀 뽑기

새봄교회 송구영신 예배에서 성도가 스마트폰으로 한 해의 약속의 말씀을 뽑는 웹앱(PWA)입니다.
설치 없이 주소(QR)로 열리고, 뽑은 말씀을 사진·배경화면으로 저장하거나 카카오톡으로 보낼 수 있습니다.

## 현재 단계

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1 | 설계 계획서 | 완료 |
| 2 | 약속 말씀 200구절 (구글 시트) | 완료 — 검토 메모는 시트 H열 |
| 3 | 개인 모드 (뽑기·카드 이미지·공유) | **이 폴더** |
| 4 | 기록 저장·예배당 모드·관리 화면 | 다음 |

## 파일 구성

```
index.html              개인 모드 화면 (시작 → 카드 뒤집기 → 결과)
css/style.css           디자인 (새벽 하늘 + 금빛, 글씨 20px 이상)
js/config.js            ★ 해마다 고치는 설정 (연도, 시트 주소, 기록 주소)
js/card.js              말씀 카드 이미지 그리기 (공유용 1080×1350, 배경화면 1080×1920)
js/app.js               말씀 불러오기, 무작위 뽑기, 같은 이름 재뽑기 방지, 공유
sw.js                   오프라인 대비 (예배당 와이파이가 끊겨도 열림)
manifest.webmanifest    홈 화면에 추가할 때의 이름·아이콘
data/sample.csv         시트를 못 읽을 때 쓰는 예비 말씀 8구절
.github/workflows/      GitHub Pages 자동 배포
```

## 처음 한 번 해야 할 일

1. **말씀 시트 공유 열기** — 구글 시트 `새봄약속 - 약속의 말씀 200구절` → 공유 → 일반 액세스를
   `링크가 있는 모든 사용자 · 뷰어`로 바꿉니다. 이것을 해야 앱이 말씀을 읽습니다.
   (이 시트에는 성경 구절만 있습니다. 성도 이름 기록은 4단계에서 **다른 시트**에 저장합니다.)
2. **GitHub 저장소 만들기** — 예: `cheol0929-thejoy/saebom-promise`. 이 폴더의 파일을 모두 올립니다.
3. **Pages 켜기** — 저장소 Settings → Pages → Source를 `GitHub Actions`로 선택.
   이후 main에 올릴 때마다 자동 배포됩니다. 주소: `https://cheol0929-thejoy.github.io/saebom-promise/`
4. 그 주소로 QR 코드를 만들어 주보·화면에 띄웁니다.

## 동작 방식

- 앱을 열 때 구글 시트 '말씀' 탭에서 **사용 = Y** 인 구절만 읽습니다. 시트만 고치면 앱에 바로 반영됩니다.
- 시트를 못 읽으면 지난번에 받아 둔 사본 → 그래도 없으면 `data/sample.csv` 순으로 씁니다.
- 뽑기는 `crypto.getRandomValues`(브라우저의 보안 난수)로 합니다.
- 같은 폰에서 같은 이름으로 다시 뽑으면 처음 받은 말씀을 다시 보여 줍니다.
  한 폰으로 가족 여럿이 뽑을 수 있게 '다른 사람 이름으로 뽑기'가 있습니다.
- 다른 성도와 같은 구절이 나와도 됩니다(확정 사항).

## 내 컴퓨터에서 시험하기

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 해마다 바꿀 것

`js/config.js`의 `YEAR`만 바꾸면 카드·화면의 연도가 모두 바뀝니다.
같은 폰에서도 해가 바뀌면 다시 뽑을 수 있습니다(저장 키에 연도가 들어 있음).
